          让助手操作整台电脑进阶

          助手会看你的整个屏幕，替你点鼠标、打字、按键：任何程序、任何窗口它都碰得到。比浏览器危险得多，默认关着。

          • 不再问，就是让它自己动手：屏幕上的任何文字都可能带着它去点、去打字。页面顶上的“停止”随时能叫停
          • 打字之前，智狐先把问你时最前面的那个程序换回来；点击的位置被别的窗口挡住了就不点

          打开之前，请先看一下

          • 屏幕上的文字（一封邮件、一个网页、一条消息）可能藏着冲着模型来的指令，把它带偏。
          • 它点得到、打得到你电脑上的任何地方。智狐只看得到像素，没法替你判断点下去会发生什么：每一步都要你看清楚。

          最稳妥的用法：在虚拟机，或者一个单独的用户账号里运行智狐，那里面不要登录你的重要账号。

              助手动手之前，要不要先问你
              
    
  
              
  
              
    
              
    
              
      
              开启之前请知道：确认是你和模型之间唯一的关卡。全部放开之后，助手读到的网页或文件里如果藏着恶意的指令，它可能在你没有看到的情况下执行命令、改动或发走你的文件；打开了“操作整台电脑”的话，还会替你点击、打字。只在你信任手头的任务、并且会盯着它的时候开启。
              
      
              
        
        
      
              
    
              
    
              选“自动允许只读命令”时，你自己加的命令也不用问。
              
    
              不管选哪一种，助手做的每一步都会显示在对话里，没有问你的那些会标上"自动允许"；保存 API 密钥的 .env 文件它始终读不了。重启程序后会恢复成"每次确认"。
              
  
              
              


  
              
    
              
      
              不用问的命令
              
      
              选了“自动允许只读命令”时（对话、定时任务、聊天通道都能选），这些命令不再问你。
              
    
              
    
  
              
  
              
    
              Windows 上命令是在 PowerShell 里运行的，这里的判断还只认得 macOS、Linux 的写法，所以暂时不起作用：每条命令都会先问你，内置的只读命令和你加的命令都一样。
              
    
              
      
      
              
        内置的只读命令，不用加
        
              ls、cat、grep、find、df、ps、git status、git log、systemctl status、journalctl、docker ps……只是看、不改东西的，已经不用问。看不懂的写法（; && | sh、> 文件、$( )、*）一律照常问；碰到 .env、助手自己的数据、~/.ssh 这类地方，哪怕只是 cat，也照常问。
              
      
              
    
              
    
              你加的命令 
              
    
              
    
                
    
                
      
      
    
                
    
                按开头的几个词比：加了 git status，git status --short 也算。后面跟什么参数都算，所以只加你放心它后面跟着任何东西的命令。bash、sudo、env 这类能运行任何命令的程序加不进来；在管道（|）里的不算。清单存在数据目录的 commands.json 里，助手自己读不到、也改不了。
