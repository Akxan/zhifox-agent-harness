        当前模型

        同一家之内换模型，对话可以接着进行；换到另一家会开始新对话。联网搜索只有 Claude 能用。

        API 密钥

        密钥保存在你自己电脑上的 .env 文件里。保存后这里只显示最后 4 位，不会再显示完整内容。

        价格 用来估算费用，单位：美元 / 每百万 token

        提示词

        告诉助手“你是谁、在什么环境里、该怎么做事”的那段话（系统提示词）。改了以后，从下一段新对话开始生效。

        每月预算 美元，可以不填

        这个月的花费超过它时提醒你一次，不会拦住任何操作。调高以后又超过了，会再提醒一次。

        导出全部数据

        会话、记忆、待办、设置、花费记录……整个数据文件夹打成一个 zip，下载到你的电脑。不含 API 密钥；MCP 配置里的密钥会换成占位符。恢复时先退出智狐，再把压缩包解压到数据文件夹里。

        提示词

        每段对话开始时发给模型的说明：它是谁、在什么环境里、该怎么做事。

        可以用的占位符，发给模型之前会换成实际的值（点一下插到光标处）：

        改过的版本不会跟着程序升级自动更新。想用新版本的内置提示词，点“恢复默认”。改过的版本存在数据目录的 prompt.md 里，也可以直接打开来改。

          开启之前请知道：确认是你和模型之间唯一的关卡。全部放开之后，助手读到的网页或文件里如果藏着恶意的指令，它可能在你没有看到的情况下执行命令、改动或发走你的文件。只在你信任手头的任务、并且会盯着它的时候开启。
