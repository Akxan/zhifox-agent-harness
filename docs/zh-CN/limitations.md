# 局限和可以接着做的方向

还做不到的、没用真实的密钥测过的，以及接下来可以做的方向。

## 局限

- Windows 上：还不能操作整台电脑；只读的命令不会自动放行（每条都问）；注销、关机时智狐来不及好好地收尾（见[在 Windows 上使用](windows.md)）。
- 后台服务（`harness service`）只对着假的 `launchctl` 和 `systemctl` 测过，测试从来不真的装上一个。macOS 上项目在"文稿""桌面""下载"里的话，
  可能要先给一个隐私权限。
- GPT 和 Gemini 没有用真实的密钥实测过（见[支持的模型](models.md#支持的模型)）。
- 语音转文字只对着本地的假转写接口测过，没有连过真的 OpenAI；特别是 OpenAI 的文档列了 OGG 格式，但没有说 Telegram 语音用的 Opus 编码收不收。
- 评测（`harness eval`）在 Claude Sonnet 5.5、Claude Opus 5.5、DeepSeek Flash 上各真跑过一遍（见[评测](evals.md)）；每个任务只跑一遍，
  用来细比还太少，GPT 和 Gemini 没跑过。
  也不检查回答请求的是不是要的那个模型（被拒绝后服务器换了备用模型，只在记录里留一句提示）。
- 用 GPT、Gemini、DeepSeek 时没有联网搜索。它们能读一个已经知道网址的网页（`web_fetch`），但读网页不是搜索。它不执行 JavaScript，
  靠脚本才显示内容的网页读出来是空的或者不全（这种用浏览器）；读不了 PDF；不走代理，只能通过 `HTTPS_PROXY` 才连得上的网站读不了。
  只对着本地的假网站测过，没有读过真的网站（包括 TLS）。
- 自定义模型接口只对着本地的假服务器测过（模仿 Ollama、LM Studio 和只做了一部分 OpenAI 格式的服务器），没有接过真的
  Ollama、LM Studio、vLLM、llama.cpp 或者网关。流式回答里不报告用量的服务器，看不到 token 数，它的对话也不会自动压缩。
  PDF 只能按 OpenAI 自己的写法发给自定义接口，本地的服务器一般读不了。
- GPT、Gemini、DeepSeek 的压缩是智狐自己做的，只在 DeepSeek 上用真实的密钥测过（门槛调低、连着压缩两次，模型照样记得之前说过的）。摘要难免丢掉细节；切口只能落在两轮之间，
  所以一轮对话自己就超出模型的上限时（比如一轮里读了很多大文件）压缩不了；不在 `config.py` 表里的模型一律按 12.8 万 token 的上限算，
  上限更大的模型会压缩得早一些。打开一段旧会话后，要等第一次请求量出它有多大，才知道要不要压缩。
- 附件只能在网页界面里发，终端界面不行。GPT 和 Gemini 看图片、GPT 读 PDF 没有用真实的密钥测过；Gemini 和 DeepSeek 读不了 PDF。
- GPT 走的是 Chat Completions 接口。OpenAI 的个别新模型如果只支持它的另一套接口，在这里用不了。
- Claude 的模型只列出程序适配过的三个，Anthropic 的其他模型接受的参数不完全一样。
- 每条命令都在一个新的 shell 里运行。只有目录会接着用（`cd` 会保留）；环境变量、alias、函数不保留，
  重新打开的对话也从工作目录重新开始，不回到当时停在的地方。
- 终端界面只在占着数据目录时才存会话：网页界面或者后台服务开着时，终端里的对话不存盘、`/open` 用不了；
  终端开着时，网页界面和后台服务开不起来。`/open` 只写出最后几条消息的文字，不是整段会话。
- 搜索把所有会话的文字放在内存里，会话非常多（几千段长对话）时会多占一些内存。正在进行、还没保存过的那一段搜不到。
  按拼音找只认完整的音节：没有模糊音（z 和 zh、n 和 l 不算一样），最后一个音节不能只敲一半，首字母只在标题里找。
- 网页界面里同时在跑的对话最多三段（`MAX_PARALLEL_CHATS`）；正在跑的那一段要等它跑完或者你停下它，才能改名、删除。终端界面只有一段对话。
- 网页界面只画 Markdown 的一部分：CommonMark 加上 GitHub 的表格、任务列表和删除线。图片不加载（只显示说明文字和网址），
  HTML 按原文显示成文字，链接只认 http、https、mailto，不支持缩进四格的代码块、引用式链接和脚注。代码着色只认常见语言的
  注释、字符串、数字和关键字。终端界面照原样显示 Markdown 原文。
- 定时任务和聊天通道只在网页界面或者 `harness serve` 开着的时候运行；定时任务最多同时三个。
  聊天通道能收文字、图片和文件（还不能收视频；语音只有 Telegram 能收，先转成文字），也能把图片和文件发回去（QQ 除外：它只收公网网址上的图片）；
  WhatsApp 和企业微信要公网地址，还不支持。Discord、Slack、飞书、钉钉、QQ
  是照着它们官方的文档写的，目前只对着本地的假服务器测过，还没有接过真的机器人。两次运行（或者一次运行和你的对话）改同一个文件的同一处时不会合并：
  每次改动整个做完，后改的那一边发现原文已经变了就会报错，模型会重新读一遍再改。
  提醒只显示在网页上（网页开着、在后台时会弹系统通知，见[网页界面](web-ui.md)里的"系统通知"），不会发到聊天软件里。
- 换成英文或西班牙语之后，智狐自己的工具写在结果里的话（比如"没有编号为 9 的待办"、"（没有输出）"、"[退出码 1]"）
  在工具卡片上、终端里按界面的语言显示，换语言时在原地跟着换；模型看到的仍然是中文，和以前一字不差。工具从别处拿回来的照原样：
  命令的输出、文件的内容、网页、MCP 的结果。还是中文的有几处较长的：网页正文前面的那几行说明（用浏览器或 web_fetch 读网页时）、
  命令被沙箱挡住时补的说明、Windows 路径写法的提醒、载入 Skill 时的文件列表、说明参数不对的那段 JSON。
  工具卡片上截短了的（超过 8000 个字）、遮过密钥的、这个版本之前存下的结果，照存下时的文字显示。
  换语言之前保存的会话里，程序发出的提示也还是当时的语言。
- Skill：`allowed-tools` 不会让任何操作免于确认（见[Skill 是怎么工作的](extensions.md#skill-是怎么工作的)）。Claude Code 的参数占位符
  （`$ARGUMENTS`、`$0`）、`!` 命令块、`context: fork`、`hooks` 等只有 Claude Code 用的字段，原样留在文件里但不起作用。
  从网址安装只支持公开的 https 链接，最多 20 MB；私有的 GitHub 仓库请先下载下来再上传。
- MCP 只支持工具，不支持 MCP 的资源（resources）和提示词（prompts）。远程服务器的 OAuth 登录还不支持；
  接受令牌的服务器加一个 `Authorization: Bearer …` 请求头就能用。已经废弃的 HTTP+SSE 连接方式不支持。
  调用到一半要向你提问的工具（elicitation）会失败并说明原因；也不让服务器借用智狐的模型（sampling）。
  MCP 工具返回的图片会交给模型，但页面上不显示。服务器写给模型的说明只给你看，不交给模型。
  对话进行中才连上或有变化的服务器，从下一段新对话开始才用得上。只对着假服务器测过，没有对着真实的第三方服务器测过。
- 浏览器只支持 Chromium 一系（Chrome、Chromium、Edge、Brave）。经由它，什么都不会进出你的磁盘：下载一律拒绝，"选择文件"的窗口被拦下，
  工具包里可选的成员（执行 JavaScript、上传文件）也没有打开。别的网站嵌进来的框里的内容读不成文字，只能截图看、按坐标点。
  网页弹出的对话框一律取消，不会替你回答。Claude 的浏览器工具包只对着本地的假 API 测过，还没有发过一次真实的 Claude 请求；
  给 GPT、Gemini、DeepSeek 的浏览器工具也没有用真实的密钥试过。Chrome 那一边是对着真的 Chrome（无界面）测过的。
- 操作整台电脑从来没有在真的屏幕上、用真实的密钥跑过：只对着假的电脑后端测过，以及在 CI 的 Ubuntu 上对着虚拟的 X11 屏幕。
  按照设计，macOS 上截图和发鼠标键盘事件的那几条路没有在真的屏幕上试过（只试过不碰屏幕的那几样：读屏幕的大小、看两样权限给了没有）；
  macOS 上上下、左右滚动的方向没有核实过；给 GPT、Gemini 的替身工具没有用真实的密钥试过。只用主屏幕；不支持 Wayland 和 Windows；
  不许碰的程序按名字认最前面的程序（macOS 上还认点击位置上的窗口），被挡在后面、只露出一部分的照样可能被截进图里。
  键盘布局不是美式的时候，打字打出来的字是对的，但快捷键按的是键的位置（按美式布局）。一次做得久了，截图会在历史里越攒越多；做一件新的事，就开一段新对话。
- 命令的沙箱：macOS 的后端（`sandbox-exec`）在 Mac 上真的测过（在工作目录里外写文件、读一个充当 `~/.ssh` 的文件、
  连本机的一个网页服务，联网开着和关着各一次）；Linux 的后端（bubblewrap）只在 CI 的 Ubuntu 上测过，没有在别的发行版、
  也没有在桌面上试过；Windows 上没有沙箱（为什么见[命令的沙箱](sandbox-and-hooks.md#命令的沙箱命令只碰得到该碰的地方)）。在沙箱里，
  装在家目录里的程序要把它的文件夹加进额外允许的路径才能用，`~` 是这次运行自己的空文件夹，macOS 上 `sudo`、`ps` 运行不了，
  localhost 也算联网。它不限制 CPU、内存和磁盘，也护不住工作目录本身，以及你以后从工作目录里运行的东西。
- 被停下的那次模型请求不记进花费账本：API 在一段回复的最后才报告用了多少，停下的回复走不到那里，
  所以停下之前模型已经读了、写了的 token（服务商可能照样收费）没有算进去。"停止"本身马上生效，模型还在想、
  还没开始回答的时候也一样；Linux 和 Windows 上这一点只在 CI 上验证过。
- Claude 的"拒绝后自动换模型重试"、"自动压缩历史"和"接着聊旧会话时丢掉对不上的思考内容"用的是 API 的
  beta 功能，其中第三个每个 Claude 请求都会带上。如果每个请求都报 400，可以在
  [harness/config.py](../../harness/config.py) 里把它们关掉（三个开关各管一个）。

## 可以接着做的方向

- 给常用的只读命令（`ls`、`git status`）加一个"本次会话不再询问"的选项。
- 给不支持联网搜索的模型接一个本地执行的搜索工具。
- 支持 MCP 的资源和提示词，以及远程 MCP 服务器的 OAuth 登录。
- 操作整台电脑支持主屏幕以外的屏幕，以及在一台测试用的电脑上用真实的 Claude 密钥试一遍。
- Windows 上命令的沙箱（AppContainer，要是文件夹的权限和 PowerShell 能弄得妥当的话）。
- 再加一种界面语言：在 `harness/locales/` 下照着 `en.json` 写一份，再在 `harness/i18n.py` 的 `LANGUAGES` 里加上它。
