# 终端界面

终端里的同一个助手：和[网页界面](web-ui.md)是同一个循环、存在同一个地方的会话，按钮换成了斜杠命令。

```bash
uv run harness
```

启动后直接打字就可以对话：

```
你> 提醒我下周五交报告
🔧 todo_add {"title": "交报告", "due": "2026-11-27"}
   ↳ {"id": 1, "title": "交报告", "due": "2026-11-27", ...}
记下了：下周五（11 月 27 日）交报告。

你> 这个目录里有哪些 Python 文件？
🔧 run_command $ find . -name "*.py"

⚠️  助手想要执行命令：

    $ find . -name "*.py"
允许吗？y 允许；回车拒绝；也可以直接输入你的意见来拒绝 >
```

| 命令 | 作用 |
|---|---|
| `/help` | 显示命令列表 |
| `/new` | 开始一段新对话（记忆和待办不受影响；离开的那一段已经存好了） |
| `/history` | 列出最近的会话：编号、标题、模型、时间（网页上聊的也在里面）；`/history 几个词` 是在所有会话里搜索，和网页用的是同一个搜索 |
| `/open` | 打开一段会话接着聊：`/open 3`（最近一次 `/history` 列出来的第几个），或者 `/open 会话的编号`。打开以后写出最后几条消息，让你知道聊到哪儿了 |
| `/todos` | 查看未完成的待办 |
| `/tools` | 查看智狐能做的事：哪些在用、会不会先问你、关着的怎么打开（和网页信息栏里的是同一份清单） |
| `/trace` | 查看最后一轮的运行记录：调用了几次模型、用了哪些工具、每一步花了多久、多少钱，外加一张用方块字符画的小瀑布图（和网页上"运行记录"是同一份数） |
| `/usage` | 查看本次运行的 token 用量和估算费用，以及今天、本月一共花了多少（设了每月预算的话也会显示） |
| `/model` | 查看各家的模型：现在用的是哪个（打 ✓）、每个能做什么、多少钱、哪一家还没有密钥（和网页上换模型的面板是同一份目录；换模型用网页界面顶上的模型按钮，快捷键 ⌘. 或 Ctrl+.） |
| `/mcp` | 查看接入的 MCP 服务器和它们的状态（添加和管理在网页界面里） |
| `/auto` | 查看或更改"要不要每次都问"：`/auto ask`、`/auto readonly`、`/auto edits`、`/auto all`（见[权限规则](tools-and-permissions.md#权限规则)） |
| `/retry` | 重新生成最后一个回答：你的消息原样再发一次 |
| `/edit` | 改最后一条消息：它会填在输入行里，改完按回车；也可以直接写 `/edit 新的文字`。和 `/retry` 一样，这一轮执行过命令、改过文件的话先问你 |
| `/undo` | 撤回最近一轮用文件工具改的文件：先列出来（后来又被改过的另外标出来），问你一句再写。重做、挑着撤回几个文件在网页界面上做 |
| `/doctor` | 自检：Python、目录的权限、哪几家有密钥、浏览器、沙箱、后台服务……哪些好、哪些有问题、怎么修（和 `uv run harness doctor` 一样，见[出了问题：先运行 harness doctor](configuration.md#出了问题先运行-harness-doctor)） |
| `/exit` | 退出（也可以用 `/quit`，或者按 Ctrl-D） |

模型回复到一半时按 Ctrl-C 可以打断它。

**会话会存下来。** 每一轮都照网页的样子存进 `data/conversations/`（被打断的那一轮也存），所以网页的会话栏里列着终端的会话、
搜索搜得到，页面上能打开、接着聊、编辑、重新生成、分叉；网页上的会话，终端里 `/history`、`/open` 也一样。`/open` 的规矩和网页上
打开一段会话一样：换回这段会话当时用的那一家、那个模型，历史交还给适配层；是用一个自定义 Agent 当角色开始的，照着它接着聊
（它不在了会说一声）；MCP 的工具重新拍一张快照。用的那一家还没有密钥的会话不打开：打开了也接着聊不了，
而且会把"现在用的模型"记成那一家，下次启动时就用它了。

一个数据目录同一时间只能有一个智狐往里写（见[在后台一直运行](background-and-servers.md#在后台一直运行)），现在终端也占着这把锁。
网页界面或者后台服务开着的时候，终端照常能聊，只是会说一声不存盘，`/history` 照样能看，`/open` 用不了；
终端开着的时候，`harness --web` 和后台服务开不起来，会说是终端占着、先在那里 `/exit`。存盘失败会说出来，
离开这段对话之前再存一次；`/new`、`/open`、`/exit` 遇到没存上的内容会先拦一下，再输入一次才放弃。
普通的 `kill`（SIGTERM；Windows 上是 Ctrl+Break）会停下正在进行的这一轮、存好盘再退出。

终端界面不运行定时任务和聊天通道。在这里也可以让助手添加或删除任务，它们在网页界面或者 `harness serve` 开着的时候运行。
